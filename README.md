# veritabaniy-netimiprojesi - Hastane ve Sağlık Hizmetleri Randevu Sistemi
İnsanların hastane, bölüm ve doktor bilgilerini inceleyerek uygun tarih ve saatte randevu alabildiği bir web platformudur. Projenin temel amacı, hastaların randevu alma sürecini daha düzenli ve kolay bir şekilde yönetebilecekleri bir sistem oluşturmaktır.
